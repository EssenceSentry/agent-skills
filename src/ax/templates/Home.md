# Agents

Your Claude Code and Codex work, archived by `ax`, and the profile of rules that shapes it.
Notes under `Sessions/` and `Runs/` and the `Scorecard` note are regenerated by `ax`, so write
your own notes under `Projects/`.

## Waiting for you

Rule proposals from `ax learn`, each with the messages that support it. Open one to read its
evidence and fix the wording if needed, then run `ax learn accept <id>` or
`ax learn reject <id>`, and `ax profile compile --apply` to load what you accepted.

`ax learn retire <id>` it.

## How it's going

[[Scorecard]] counts corrections, progress nudges, guard blocks, worker denials and errors
that keep coming back, week by week. Refresh it with `ax scorecard --note`. Live jobs, usage
and runs are on the local dashboard: run `ax serve` and open http://127.0.0.1:8765.

## Your rules

Compiled into both tools by `ax profile compile --apply`. Edit a rule's note to change it.
Maturity and confidence come from the evidence `ax sync` finds: a rule is new for a month,
then established, proven after three months with fresh evidence and nothing against it,
and doubtful when the evidence against it outweighs the evidence for it.
